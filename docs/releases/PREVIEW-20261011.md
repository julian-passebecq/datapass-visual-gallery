3. V1 acceptance remains incomplete: Mongo-backed semantic retrieval, shared collections, optimized thumbs, generated-image import, controlled publishing and Edge extension integration. See `spec/features.csv` and `spec/ux.csv`.
4. Production CI/CD through GitHub-connected Cloudflare Builds is not configured; a dedicated deployment credential is still needed if that automated path is desired.
5. Main stays unmerged; no data was promoted from private to public. Neither Windows nor the user's authenticated browser has been qualified remotely.
